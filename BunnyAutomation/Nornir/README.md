What is Nornir?
 - An automation platform for Network devices that uses Python

Why is it used?
 - Can perform concurrent task execution. Allowing for faster results
 - Inventory Management
 - Agentless Automation Solution
 - Flexible
 - Nornir can use multiple Network Solutions such as Napalm, Scrapli and Netmiko (All these come with NornirPlugins ie nornir-napalm)

Nornir vs Ansible
 - Ansible: Written in YAML, easy to read/troubleshoot with no prior dev experience. Not as verbose, limited to YAML structure
 - Nornir: Written in Python, need experience in Python. More verbose, not limited and much faster execution. Improved error handling
